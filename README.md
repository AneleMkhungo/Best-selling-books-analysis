# Best-selling-books-analysis
Analyzing Best-Selling Amazon Books with Pandas

Project Overview

This project explores Amazon’s best-selling books dataset using Python, Pandas, and Matplotlib. The goal is to identify patterns in book ratings, prices, reviews, genres, and bestseller appearances over time.

Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook (Anaconda)

Analysis Questions

1. Who are the top best-selling authors?
2. Fiction vs Non-Fiction: Which has more appearances and higher average ratings?
3. Does book price relate to user ratings and reviews?
4. How do bestseller appearances and average prices change over time?
5. What correlations exist between reviews, ratings, and prices?

Key Skills

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Aggregation using GroupBy
* Data Visualization
* Correlation Analysis
* Data Interpretation

Conclusion

This project demonstrates the use of Python for data analysis and explores trends and relationships within Amazon’s best-selling books dataset.
